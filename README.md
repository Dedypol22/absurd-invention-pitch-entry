# The Absurd Invention Pitch

This entry pitches one ridiculous invention for the make.fun bounty "One-Sentence Absurd Invention Pitch": a self-drying umbrella that solves the tiny everyday annoyance of a wet umbrella dripping indoors by shaking itself dry like a wet dog, then apologising to everyone it just sprayed.

> "A self-drying umbrella that shakes itself like a wet dog the moment you step inside, then apologises to everyone it just sprayed."
